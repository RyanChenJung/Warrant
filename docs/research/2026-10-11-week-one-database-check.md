## Caveats

- **These databases may be more synthetic than BIRD's (ADR 0009).** In 639 of the 728 coded text columns the most frequent code is at most 1.25 times as frequent as the least frequent one, an even spread real business data rarely shows, and relations that real data carries (such as totals of components) are mostly absent.
- **Identities are rare.** The vendored identity search finds 1 in the 175 tables, so a column-formula defect elsewhere would have to inject one as a data change.
- **The link detector sees almost none of the declared foreign keys.** 256 of the 257 declared foreign keys join columns with different names (for example `signals.telescref -> telescopes.telescregistry`). The vendored Gloss link detector pairs key columns by name only (`name_matched_pairs` in `gloss/detect/link.py`), so it sees only `alien: telescopes.observstation -> observatories.observstation`. Each coverage candidate below marks which of its related keys are same-named.
- **What the identity search mirrors.** `numeric_columns`, `_identities` and `_best_combo` of `gloss/detect/rule.py`, run in Python over SQLite with every value read as text, as the CSV export the battery reads would hold it. The battery's GRAIN detector also restricts the rows to top-level records on tables with a self-reference; this check does not. Like Gloss, the pool includes numeric key columns.

## Thresholds

| Check | Rule |
|---|---|
| Numeric column | Every populated value (not NULL, not empty) parses as a number; in table column order |
| Identity pool | The first 12 numeric columns of a table |
| Identity | A target equals the sum of 2 or 3 other pool columns within an absolute tolerance of 0.005, on at least 80% of the rows where the target parses and is non-zero; a NULL or unparsable component counts as 0; best share per target, ties to fewer terms |
| Injectable table | At least 3 numeric columns in the pool |
| Coded value column | 2 to 12 distinct non-null values; declared primary-key and foreign-key columns skipped |
| Documented codes | Every code occurs in the column's meaning (whole word, any case) |
| Knowledge-base mentions | Column name: whole word, any case, in an entry's knowledge, description or definition. Code: whole word, same case, codes with a letter only. `value_illustration` entry: an entry of that type whose title is the column name, alone or before a colon |
| Status column | A coded value column whose values are not all numeric |
| Status-like | The column name contains stat, stage, phase, type, categ, flag, level, lvl, class, tier or grade (or ends in lev), or its meaning, outside any `Data type:` clause, has the word status, state, stage, phase, type, category, flag, level, class, classification, tier or grade |
